# Data directory

The source data used in the original analysis were ten company Form 10-K HTML files supplied through the University of Melbourne course environment. The files are not included in this public portfolio repository.

To reproduce the workflow with independently obtained public filings, download the relevant Form 10-K documents from SEC EDGAR and save them here using these filenames:

```text
NVDA_latest_10K.html
GOOGL_latest_10K.html
MSFT_latest_10K.html
AMZN_latest_10K.html
META_latest_10K.html
TSLA_latest_10K.html
IBM_latest_10K.html
INTC_latest_10K.html
CRM_latest_10K.html
ORCL_latest_10K.html
```

## Limitations

- Filing dates and document contents may differ from the original course dataset.
- New Gemini runs may not exactly reproduce the summarised portfolio results.
- Verify each model-extracted claim against the corresponding filing before using it.
