# Project Assets

## NLP Methodology Overview

[`project-overview.svg`](project-overview.svg) presents the project's methodological architecture for extracting AI-related information from long-form Form 10-K filings.



The visual was created specifically for this public portfolio adaptation and was not part of the original University of Melbourne coursework submission. Empirical outputs are deliberately shown as secondary research artifacts because the primary portfolio contribution is the NLP methodology.
